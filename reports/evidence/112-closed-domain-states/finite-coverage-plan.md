# Small finite library-coverage slice (planning only)

## Contract and current gap

`docs/PRD.md:149-177,194-197` requires own attached tests to cover each Bool/enum input value per parameter and each finite declared return value; Option/Result alternatives and finite payloads are included. The observation must come from the tested function's actual execution, not expectation constants or unrelated callers, and qualification must be bound to the tested revision/dependencies. `Runtime.fs:1999-2133` runs an actual test body in a dedicated trace and evaluates a pure expectation separately; `Runtime.fs:578-585,1470-1510` currently records only own source sites/branch outcomes by word name. `Runtime.fs:2177-2191,2851-2860,4503-4513,4637-4644` expose/enforce structural coverage only. The enum guard at `Runtime.fs:481-486` rightly prevents new enum-bearing authored library words today.

## Bounded implementation

1. Add a test-only user-function entry/normal-return observation hook at `IrInterpreter.fs:413-444` (the verified `UserWordTarget` path). Record the exact `FunctionId` and `FunctionRevision`, parameter index/value on entry, and return index/value only after normal completion. Compare those with the test owner's identity/revision from the same verified snapshot in `Runtime.fs`; do not match a display name. The hook should be inactive for ordinary eval/examples. The interpreter can decode only matching calls into existing `Value` (`BoolValue`, `EnumValue`, `UnitValue`, `OptionValue`, `ResultValue`) and pass them to the host; no new provider or test syntax is needed. Inputs to an invocation that later faults are observed, but only a passing attached test can contribute them; faulted calls have no return observations. Repeated and nested real invocations of the target within its own test aggregate. A helper call into a different word, setup constants/provider calls, mock/expectation execution, and unrelated test owners add nothing. If setup itself invokes the target, that is a real target invocation and counts; distinguishing its *intent* from an exercise call would require a new explicit test marker and is outside this slice.
2. Add a small finite-obligation function in `Runtime.fs` over the verified signature and frozen nominal enum table. Inputs: **each direct Bool or enum parameter independently** (`arg[0]=false/true`, `arg[1]=State.pending/...`); no Cartesian input product claim. Returns: each output position's leaf obligations for Bool, enum, Unit, and recursively Option/Result. `Option<Int>` requires `none` and `some` tags; `Option<Bool>` requires `none`, `some.false`, `some.true`; `Result<Enum,String>` requires every `ok.<case>` and `error`; `Result<Option<Bool>,Unit>` expands both nested alternatives. Scalar Int/Float/String and List payloads are not enumerated; their enclosing Option/Result tags still are. Require a cap (for example 256 finite leaves per output) and return an explicit unsupported-policy diagnostic if exceeded. Records/nominal scalars with finite-bearing fields are not silently declared complete: either implement their product domain here or, for this bounded slice, block new library qualification with `LIBRARY_FINITE_COVERAGE_UNSUPPORTED` and report the unsupported return type. A signature with no finite input/output obligations is vacuously complete only after a passing own test and the existing structural gate. Broad finite return types with impossible leaves fail with listed missing leaves; do not infer reachability from authored tests.
3. Add observed input/return sets and a binding stamp to `Trace`/`TestCaseResult` (`Runtime.fs:97-110,1999-2020`). Aggregate only passed own attached results for finite gates. The stamp includes target `WordId`/revision and exact reachable dependency identities/revisions/source hashes plus frozen type-source hashes (or an equivalent semantic IR closure digest); compare to the current snapshot before exposing a result as current. Do not use `VerifiedIrProgram` reference equality or the existing whole-program compiler fingerprint: `commitCandidates` checks tests on `durableSnapshot` and later activates a separately compiled `finalSnapshot` (`Runtime.fs:2843-2887`), while the compiler fingerprint includes maturity/status (`Compiler.fs:866-914`). Existing `lastResults <- []` mutation resets remain, but the stamp makes stale dependency observations impossible to credit.
4. Use one `finiteCoverage` object in `coverageJson`/`describe`/`test` responses: per-parameter and per-return required/observed/missing labels, target identity/revision, policy status (`not-run`, `complete`, `incomplete`, `unsupported`), and an explicit current-policy qualification flag combining passing tests, structural coverage, and finite coverage. Preserve existing coverage fields and response shape. After the finite gate is active, remove the blanket enum guard only for words whose finite obligations are supported and complete; route commit, replacement, rename/rewrite, and deprecate through one shared coverage-gate helper to avoid diverging checks. Keep historical library maturity on reload, but show `not-run`/`incomplete` under the **current** finite policy until current bound tests prove it; never report old structural qualification as a finite pass. Do not rewrite frozen fixtures or add a manifest-format field for transient observations.

- `src/AgentLang.Core/IrInterpreter.fs`: verified entry/return observation of actual user function; avoid decoding unrelated invocations.
- `src/AgentLang.Core/Runtime.fs`: finite obligation/observation/stamp, trace and result fields, introspection, shared gate in commit/replace/rename/deprecate, and retirement of the blanket enum guard for supported complete words. `TypedIR.fs` needs no new opcode or persistence format; use existing verified `IrFunction` signature and nominal table. `Storage.fs`, parser, and historic source fixtures need no edits.
- `tests/AgentLang.Flow.Runtime.Tests/Program.fs` (and a small Stack runtime test only if useful): branchless `Bool -> Bool` fails for a missing input or return and passes with true/false; enum input and enum return each fail on one missing case and pass once covered; two Bool parameters require independent coverage without claiming all four combinations; `Option<Bool>` and `Result<Enum,Int>` require expanded leaves/tags; `Option<Int>` requires both tags; a missing/unreachable finite return leaf blocks library qualification. A test setup constant, helper of another owner, and pure expectation value must not credit finite coverage; an actual nested call to the target in its attached test should. Faulted target contributes input only when the expected-error test passes. Verify exact target revision/dependency replacement invalidates observations, reload shows `not-run`, and a historical library remains loadable but has no false current-policy pass. Exercise commit, replacement, rename, and deprecate through the same gate. Existing frozen business fixtures remain untouched.

This slice gives finite-value evidence and an honest gate, not semantic proof of the business rule or exhaustive parameter combinations.
