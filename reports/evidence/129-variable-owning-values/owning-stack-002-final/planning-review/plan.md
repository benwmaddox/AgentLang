# Next owning-stack slice: nested variable-sized String

Status: bounded planning only (2026-10-08). No implementation or semantic IR change is proposed here. The canonical checkout is `prototype`; unrelated untracked retention-trial files are present and must be left alone. This plan extends the existing `OwningStackAot`/`owning_stack_runtime` path after 7579a39, rather than adding a second owning backend.

## Decision and acceptance boundary

Add **String as the first variable-sized owned leaf**, then permit it inside acyclic records. Keep Int, Bool, Unit, empty records, and the current effect-free operation gate. Existing `IrString`, `LString`, `StringValue`, `MakeRecord`, `GetRecordField`, `StoreLocal`, `LoadLocal`, `Scope`, `If`, user calls, and generic `dup`/`drop` already express the workload. Add only the existing, verified `string.concat` and `string.length` primitives so the first slice proves native variable growth and code-unit semantics. Do not add source syntax or alter `TypedIR.fs`, the verifier's value semantics, or the interpreter. Defer List, Option/Result, other string primitives, arbitrary validators/effects, and async; those add separate semantic and dynamic allocation problems.

Acceptance requires a real LLVM execution of new `TextState -> TextEnvelope -> TextLeaf(text: String)` record types, with at least two different UTF-16 code-unit lengths; retain the existing fixed `State`/`Envelope`/`Leaf` definitions and controls. The same verified body must exercise independent `dup`/`drop`, local load/store and scope exit, `string.concat` growth, `string.length`, a user-word return, record projection through the nested variable field, and a bounded failure after an actual allocation. Caller retained bytes stay untouched on every failure. Trace/metrics must show distinct physical copy ranges, reclaimed cursor and zero final live owners, with literal typed/byte expectations independent of the owning encoder.

## Physical layout and ownership constraints

Use one canonical, self-contained inline encoding in the caller-owned bounded stack: `String = u32 UTF-16 code-unit count, u32 zero reserved, 2*count little-endian code-unit bytes, zero padding to 8-byte alignment`. Its extent is `align8(8 + 2*count)` and logical live payload is `8 + 2*count`; the entire extent is initialized. Preserve all verified .NET String code-unit sequences, including isolated high/low surrogates, embedded NUL, and a pair formed only by concatenating two separately valid strings. `string.length` returns the code-unit count, matching `IrInterpreter.fs`; it does not count Unicode scalar values or encoded bytes. Reject malformed lengths, nonzero reserved/padding, and size arithmetic overflow, but never reject a code-unit sequence merely because it is ill-formed Unicode. A zero-length String still has an eight-byte header. Record fields remain in verified declaration order; each field starts after the previous field's **runtime extent**, so no static offset is assumed for a field after String. A record's extent is the sum of child extents (minimum eight-byte token for an entirely empty record); payload is the sum of child payloads. Existing empty-record-in-parent zero-width behavior remains explicit. All nested offsets and extents are checked against the active initialized owner range and capacity before dereference. No pointer to managed strings, host buffers, shared graph, retained region, or callee frame may survive as a value.

Replace the emitter's static `PayloadBytes`/`ExtentBytes` and `OwningStackEntry.RelativeOffset` assumptions at dynamic sites with checked runtime size/offset calculation; static types may remain compile-time fast paths. A small type-directed scanner for String/record extents, used consistently by native operations and host codec, is preferable to per-operation ad hoc field math. Keep type metadata immutable; value sizes belong to each owner instance. Keep the public `OwningStackAot.compile` and `Execute`/`ExecuteInto` signatures. For layout metadata, retain exact `PayloadBytes`/`ExtentBytes`/`OffsetBytes` for fixed types/fields; mark dynamic sizes and offsets explicitly (e.g. `IsDynamic` and `-1` for unavailable constants, plus minimum sizes), and version the experiment report/fixture if their prior meaning changes. Do not present a minimum or a particular runtime instance as a fixed type size. The existing verifier/registry gate must still reject unsupported operations and forged targets before native entry.

The current fixed local prefix (`buildFunctionPlan`, `binding.ReservedBytes`) cannot store arbitrary String lengths faithfully. Use a packed frame with local owners and operand owners in the same bounded stack buffer, plus bounded per-frame *metadata* for local slot offset/extent/payload/active state. `StoreLocal` transfers the top operand into its local slot; local replacement, same-slot shadowing, and scope exit compact or shift the affected suffix and update all later local offsets and operand base. `LoadLocal` and `dup` allocate independent byte copies. `drop` and scope exit poison/reclaim exact former extents; no dead holes or per-local maximum-sized slabs. Metadata may live in native/LLVM frame storage but never carry payload or preserve an owner after its scope. Every memmove/reserve is checked before mutation and counted as moved/copy bytes; on sticky failure, unwind/poison and restore cursor, live-local, and live-operand counters. Branch joins share verified types but reconcile runtime offsets from the selected path. A direct C fixture must replace a local with a shorter and then a longer String while another local and operand are live, to prove that relocated metadata and owners remain valid.

`string.concat` reads two String owners, checks combined code-unit count and output extent, reserves exact output scratch above them, copies both code-unit runs without normalization, writes one canonical header/padding, then transfers the new owner down and reclaims the consumed owners/scratch. Capacity preflight happens before any source is consumed. `string.length` consumes one String and produces an Int equal to the u32 code-unit count; it may read a canonical header after bounds validation, and drops/reclaims the String owner. Use the existing interpreter limit/diagnostic behavior for concatenation where it is semantic rather than a physical capacity failure; keep the owning capacity error distinct.

Calls cannot pre-reserve a fixed result size. Use the actual argument extents, callee's actual output extents, and a result destination in the caller-owned region; preflight all capacity required for temporary overlap, move complete outputs without aliasing, and reclaim the callee frame. Multi-output and zero-output behavior should continue to work. The entry wrapper derives input/output lengths from actual encoded values; it publishes only after full success to the existing bounded staging/managed decode-and-commit path. Capacity diagnostics must state checked required/available bytes, including host encoding, stack, and retained-output boundaries. Keep the raw ABI capacity cap at `INT32_MAX` or replace its offset proof with widened checks.

## Concrete fixtures

1. `TextLeaf(text: String) -> TextEnvelope(leaf: TextLeaf, tag: Int) -> TextState(last: TextEnvelope)`: use `""`, ASCII `"a"`, BMP `"é"` (one code unit), and astral `"🧪"` (two code units). Put a scalar *after* the nested String to force a dynamic field offset; pin complete little-endian bytes and zero padding by literal hex, not by reusing the encoder under test. Include two distinct retained output lengths.
2. A source/verified body concatenates a nested String with a suffix, checks `string.length`, duplicates a nested value, drops one copy, stores the survivor in a local, reloads it, then returns it through a user call. Trace asserts disjoint copy ranges, dropped copy poison/reclaim, survivor source through return and retained copy, and `FinalCursorBytes = FinalLiveStackBytes = 0`. A separate scope case replaces/shadows a String-bearing local with a different length and verifies the outer owner survives and the inner extent is reclaimed; use a compiler-minted verified IR case if the Flow parser still cannot express same-`LocalSlot` shadowing.
3. Compiler-minted verified `LString` and direct `Value` inputs include isolated high surrogate, isolated low surrogate, embedded NUL, and concat of high-surrogate and low-surrogate operands that forms a pair. Assert exact UTF-16 code units and lengths before/after native return; no UTF-8 conversion, replacement character, normalization, or rejection. Flow source need not spell an isolated surrogate if its parser cannot express it.
4. Stack capacity one byte below the measured needed extent and retained capacity one byte below the actual serialized result; both fail at the stated boundary, leave a sentinel caller buffer untouched, and finish with cursor/live owners zero. Also test an invalid host `Value` against the verified input type before native invocation and malformed raw String headers/lengths/padding in C. Keep one valid near-boundary case.

## Control comparison

`IrInterpreter` already handles String and records. The existing ABI3 `LlvmAot` validator/host codec rejects `IrString`, so run the **same verified body** through the interpreter and owning LLVM, plus independent literal byte/layout/capacity oracles. Do not expand ABI3 solely to create a String comparison, imply native-control parity for this fixture, or draw a performance conclusion. Keep ABI3 completely out of the owning value representation/runtime. Existing fixed-body three-backend controls still run unchanged.
