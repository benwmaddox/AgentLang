No arithmetic blocker found. UnitBasisPoints validator accepts exactly 0..10000 inclusive. The total function sets q=amount/10000, r=amount-q*10000, and returns q*rate+(r*rate)/10000 as Money. q*10000 is representable; r has the amount sign and magnitude below 10000. Therefore q*rate is bounded by q*10000, and |r*rate| <=99,990,000. Both resulting terms have the amount sign; their sum has magnitude no greater than the original amount for a valid rate. This includes Int64.MinValue, full rate and zero rate. Integer division truncates toward zero, giving exactly trunc(amount*rate/10000), without a wide product or unreachable error branch. The fixed 9000 caller constructs the valid rate explicitly and returns Money directly.

Refinement trust: UnitBasisPoints.new is the generated scalar constructor. IrInterpreter invokes its verified ValidatorCall and only mints RuntimeScalar on true; false yields REFINEMENT_FAILED. Direct use of that constructor does not bypass bounds. UnwrapScalar checks the nominal key and returns the payload without rerunning validation, so safety relies on provenance. Core typed entry accepts primitive Int/Bool/Unit or roots from opaque IrInterpreterResult, whose internal constructor and same VerifiedIrProgram identity check prevent a public NamedValue from being injected as a refined root. Persistence stores definitions and stable validator references, not arbitrary runtime Value objects; source reload reconstructs the type/validator contract. Runtime guards freeze a persistent scalar's validator closure against replacement/rename. Ordinary authored calls using this reviewed, unchanged type consequently satisfy the proof's precondition.

Scope limit: nominal type name/shape alone is not a global proof. A different manually constructed compiler context could define a different validator under the same displayed name. Raw foreign/native ABI callers can forge nominal payloads unless their boundary validates refinements; structural arena/type checks do not alone prove the numeric bound. Do not claim safety for forged host values, corrupted private state or a changed validator contract. The claim is total arithmetic for valid UnitBasisPoints values produced under this reviewed type contract. No new untrusted-host validation or native support was reviewed or introduced.
