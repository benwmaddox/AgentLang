# Campfire sign-in foundation evidence

The final combined gate is `validation/combined-02/receipt.json` (20 passing
checks). Source snapshots, dependency restore/audit evidence, earlier failing
attempts and final passing runtime/storage receipts are retained separately.
Shared restoration and synthetic HTTP traces are included under validation/shared.

All credential/cookie fixtures are public synthetic test data. SQLite databases,
package/executable binaries and temporary build data are excluded. The manifest
contains every archive member hash and the verified ZIP hash.

This is evidence of a typed sign-in foundation and existing HTTP regression.
Public HTTP login and full Campfire migration are not complete.
