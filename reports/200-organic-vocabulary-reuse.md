# 200 — Organic vocabulary creation and later reuse

Status: pre-dispatch preparation accepted. No participants have run.

This is the next bounded test of the question left open by
[report 199](199-efficacy-decision-after-reference-maintenance.md): does a useful
abstraction selected by one coding agent help a fresh later agent make a correct
change? It is one sequential chain, not a comparative reliability estimate.
The AI agents remain external developers; the language contains no built-in agent.

The [frozen study plan](../experiments/AgentLang.SubagentTrials/organic-reuse-200/PLAN.md)
uses the existing subscription seed. A creator adds monthly and annual renewal
operations. A shared helper is optional and unnamed. If the creator passes
independent behavior, preservation and library gates and leaves an eligible
production helper, a fresh successor receives only its accepted project and a
batch-renewal task. No helper is a valid endpoint; it does not justify dispatching
or claiming successor reuse.

helper creation, discovery and production reuse. The model prepares 66 creator
observations and nine held-out successor cases. Library publication and passing
agent-authored tests cannot substitute for the independent observations.
