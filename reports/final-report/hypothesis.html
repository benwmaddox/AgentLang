Agent research: the hypothesis and what tested it

The project existed to test one idea: whether an accumulated, discoverable, strongly typed vocabulary helps fresh AI coding agents make reliable changes. Twenty-odd agent studies ran between day 2 and day 8. They showed the mechanism works. They did not show it beats an ordinary language.

The hypothesis as stated

"The primary hypothesis is that accumulated, discoverable, strongly typed vocabulary helps fresh AI coding agents make reliable changes, find established behavior, catch violations before committing, and recover from errors. […] Lower token, turn and interaction costs are secondary benefits to measure. Conventional F# is a strong correctness baseline. […] Implementing a language is an enabling step, not evidence for the hypothesis."

— docs/PRD.md, "Purpose and hypothesis"

The design followed from that. Code lives as words (named functions) in a persistent dictionary. Agents work through a JSON-lines command protocol (help, search, describe, source, define, test, commit). They never edit files directly. Every committed word needs an attached passing test, and library words also need full instruction and branch coverage. Types are nominal and refined, matches are exhaustive, and effects are declared. The intent was that a later agent could find what an earlier one built, trust it, and change it safely.

How the studies were run

The method itself is one of the project's better outputs. It is worth reusing even though the hypothesis failed.

  • External agents only. The runtime contains no AI. Fresh agent sessions acted as participants through a broker. The broker logged every exchange and enforced budgets and launch allowlists.
  • Matched arms. There were three arms:
    • Retained: an AgentLang project with prior vocabulary.
    • Reset: a rich AgentLang domain without the agent-built vocabulary.
    • Conventional F#: hash-guarded patching and local self-tests.
    Early studies also had a sparse Flat arm.
  • Frozen protocols. Tasks, oracles, controls and runtime pins were frozen and hashed before dispatch. Changes after a run were labelled as supplements, never merged into the original score.
  • Independent oracles. An independent model scored the behaviour, separately from the participant's own tests. Calibrated wrong controls (deliberately incorrect implementations) proved the oracle could fail a wrong answer.
  • Separate endpoints. Each of these was scored on its own and never collapsed into one success number:
    • behaviour;
    • preservation of inherited tests and examples;
    • library qualification;
    • normal session completion;
    • actual reuse in the production call graph.
  • Evidence archives. Traces, receipts and sources were sealed into hashed archives and scanned for secrets before publication.

The method's weakness was sample size. Most comparisons had one or two participants per arm, a fixed launch order and unequal seeds. Every report says so. None of the results can estimate a population success rate or attribute cause.

Why AgentLang cost more interactions

The traces show friction in discovery and test authoring, not in the domain logic:

  • Name and selector errors. In 231, the agent tried RenewalTiming.new; the generated constructor is the lower-camel renewalTiming.new. Of the nine structured errors in 228, four were name or selector errors.
  • Many small queries. The 231 agent made 22 test-source queries, 18 describe calls and 12 source calls. A file-based F# agent reads one file once.
  • Mandatory library qualification. Writing tests that meet full coverage and finite-case rules is extra work that F# self-tests do not require.
  • Familiarity. Agents already know F# and do not know Flow. No amount of in-runtime help fully closes that gap in one session.

Why preservation failed only in AgentLang

In both failures (222, 231), the agent changed an unrelated inherited test input, the ID 30000000-…-0001 to 33000000-…-0001. The test still passed, because that case short-circuits on an earlier failure. Stable IDs and revision history made the change visible to reviewers, but nothing prevented it. The definition-level edit model meant agents re-submitted whole test sets, so collateral edits rode along. F# agents patched narrow hunks of a file.

What the gates did and did not prove

Useful

  • Strong nominal and refined types, exhaustive matching and declared effects consistently caught mistakes before commit. Errors came back as named, structured codes, and agents recovered from them.
  • Atomic multi-word replacement with caller re-testing made typed API migrations (179, 231) safe to publish.
  • Stable IDs and revision history made every change inspectable after the fact.

Not sufficient

  • In 084, an agent's discount rule passed 8/8 own tests and 20/20 instruction coverage, yet scored 42/54 on the independent oracle.
  • In 182, deliberately wrong migration controls passed their tests and library qualification, then failed 10 of 37 independent cases.
  • Coverage checks that code was exercised, not that the expected values are right. Agents sometimes derived expected values from the implementation under test.
  • Gates did not stop collateral edits to inherited tests.

Assessment

The research was conducted carefully and reported honestly. The checkpoints never overstated the result, which is to the project's credit. But by 11 October the evidence was consistent. The vocabulary mechanism works, and it does not make agents more reliable or cheaper than in a mainstream typed language they already know. On 11–12 October the project's priority moved to porting Campfire natively. The PRD calls this "use application implementation and subsequent maintenance to investigate reliability". The later-agent maintenance study on Campfire was never run, so the primary hypothesis was not tested again after day 8.

A fair reading: the hypothesis was not refuted at scale, but the small, careful samples gave no reason to expect a large effect. The costs were also clear: an unfamiliar language and a chatty protocol. Any effect would have to overcome them.
