Reproducing the main results

# Build and test (Windows, .NET 9, PowerShell or Git Bash)
dotnet build src/AgentLang.FlowHttp -c Release
dotnet run -c Release --project tests/AgentLang.Flow.Runtime.Tests

# Campfire server: unverified exe first, then the verified O2 build
scripts/Build-CampfireFlowServer.ps1 -TwoPart -OutDir .agentlang/campfire-flow-server/windows

# Linux build (WSL2); see docs/LINUX-SERVER-PLAN.md for the benchmark harness
scripts/Build-CampfireFlowServer.ps1 -Target linux-x64 -OutDir .agentlang/campfire-flow-server/linux

# Build-time probe: time to define, commit and replace one word in the loaded Campfire project
AGENTLANG_BUILD_TIMING=1 AGENTLANG_BUILD_ADD_PROBE=1 \
  dotnet src/AgentLang.FlowHttp/bin/Release/net9.0/AgentLang.FlowHttp.dll emit \
  --app campfire.server --target windows-x64 --out <dir> --source <each Campfire .flow file>

Switches

VariableEffect
AGENTLANG_INCREMENTAL=0Disables incremental snapshot extension (always compile from scratch).
AGENTLANG_INCREMENTAL_CHECK=1Also compiles every extension from scratch and fails on any difference, including stale bindings.
AGENTLANG_INCREMENTAL_LOG=<file>Appends one line per extension: added, recompiled, attachments, files.
AGENTLANG_BUILD_TIMING=1Prints phase timings for define, commit, lowering, publish and emit.
AGENTLANG_BUILD_ADD_PROBE=1During emit, adds, commits and replaces probe words, and checks that their tests ran.

Caveats

  • Benchmarks. They are the project's own, on one machine (WSL2 on Windows, pinned vCPUs), with a pre-declared protocol. Rails was wait-bound in every cell. The Rust reference is another port, not an official implementation.
  • Agent studies. They used one or two participants per arm, a fixed launch order, and unequal seeds in places. Broker exchanges and wire bytes are protocol measures, not model tokens. Results from different protocols were never pooled, and this report doesn't pool them either.
  • Who built it. AI coding agents did most of the implementation, directed by one developer. That is itself a data point about agent-built toolchains. It also means the code reflects many short sessions, not a single designer.
  • Private data. Fixture credentials and other private evidence are excluded from the repository. Evidence archives were scanned for secret values before publication.

Open items at archive

  • Campfire: WebSockets and live updates, writes on the portable server, sign-in and out with libxcrypt or crypt_blowfish, account logo, room creation, bots, uploads, a typed schema and migrations.
  • Language: lambdas, string ordering, bitwise operators, match as a statement, and native lowering for every builtin.
  • Performance: a string builder to cut ~650 KB of scratch per message, and the cached gap to Rust (0.6×).
  • Tooling: make the incremental cross-check mandatory in tests. Reduce the ~8 s full test run and the ~2 s first publish.
  • Research: the matched mainstream-language study proposed in Lessons.
