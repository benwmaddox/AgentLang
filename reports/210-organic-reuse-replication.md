# 210 — Fresh replication of organic vocabulary creation

Status: preflight accepted on 2026-10-11; creator dispatch is next. No new agent
outcome is claimed in this preparation report.

The primary efficacy question remains whether agents independently create useful
typed vocabulary that a later agent discovers and reuses. Trial 200 completed its
task without an eligible new shared helper, so its frozen stop rule prevented a
successor. This separately named replication gives a fresh creator the same task,
seed and eligibility rules, with no knowledge of that result. It does not prompt
factoring or change the original result.

The [predeclared plan](../experiments/AgentLang.SubagentTrials/organic-reuse-210/PLAN.md)
requires two fixed-term renewal library functions. The shared helper is optional
and unnamed. Only a correct creator that preserves inherited evidence and leaves
a qualifying helper permits a fresh successor to attempt the held-out batch task.
An empty helper set is a valid endpoint. Behavior, preservation, library maturity,
creation, discovery and production reuse remain separate criteria.

The public packets, case export and seed inventory are byte-identical to 200.
The copied scorer changes only study/output identities; the control runner also
uses a neutral current-runtime pin status. Root reviewed those differences.
The current runtime was freshly built from `87c82d0`, rather than silently using
the older participant binary. Runtime changes and hashes are preserved, so this
is a repeated task opportunity on the current build, not an identical-runtime
replication or a causal comparison.

Local validation:

- Release CLI build: zero warnings and errors.
- Existing V2 broker verifier: 37 focused checks passed.
- Python-only model/scorer checks: 66 creator cases, nine successor cases and
  75 typed observation expressions, plus helper, preservation and discovery checks.
- Six executable behavior controls: correct creator 66/66 and correct successor
  9/9; deliberate creator mutants match 40/66 and 36/66; successor mutants match
  4/9 and 6/9 and fail their intended cases. All 225 observations execute without
  setup errors. The inherited suite passes 137/137 in each control process.

The first control command was started before the copied validator update finished.
It stopped at the old runtime-pin status check before running the runtime. Its
receipt is retained separately from the accepted six-control attempt.

[Sealed pre-dispatch evidence](evidence/210-organic-reuse-replication/preflight.zip)
and [index](evidence/210-organic-reuse-replication/preflight.index.json) preserve
the current source/runtime hashes, reviewed study inputs, initial actor project,
closed preflight receipts and verifier traces. Every archive member was reopened
and its length and SHA256 checked. Participant outputs will be archived separately.

Participants use fresh contexts and assigned broker sessions, Luna/max, at most
100 exchanges, virtual I/O and no external effect grants. The broker is not an OS
sandbox; external-tool isolation is prompt-governed and must be disclosed.
No public listener, new external capability or language escape hatch is introduced.

This preparation changes no efficacy conclusion in [report 203](203-efficacy-decision-after-organic-creation.md).
One additional creator can supply another observation of this particular task;
it cannot estimate comparative reliability, context savings or a native runtime
advantage. No helper means no successor and no downstream reuse claim.
