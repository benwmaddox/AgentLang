# Rails cookie compatibility fixtures

These standalone fixtures are a narrow subset of `.agentlang/campfire-reference/vectors/rails_compat.json`, generated by `.agentlang/campfire-reference/reference-tools/rails_compat_vectors.rb`. The test project reads only this file and does not depend on the ignored reference checkout at runtime.

The subset contains 2 PBKDF2 key vectors, 4 signed-cookie generation cases, 16 signed-cookie verification cases, 1 encrypted-session generation record, 8 encrypted-cookie verification cases, and all 7 Rack cookie escaping records. It includes a U+2028/U+2029 token case to confirm Rails' literal UTF-8 serialization. The session values and `secret_key_base` are published synthetic test data. The test secret is not a production credential.

Expiry metadata requires an ISO timestamp with an explicit `Z` or `±HH:mm` offset. The parser supports up to seven fractional-second digits because `DateTimeOffset` has 100-nanosecond precision; Rails-generated expiry metadata uses three digits. Longer precision and timestamps without a timezone are rejected.
