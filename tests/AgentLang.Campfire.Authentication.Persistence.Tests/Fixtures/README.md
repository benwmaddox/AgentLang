# Rails password vectors

These are a small copied subset of `.agentlang/campfire-reference/vectors/rails_compat.json`'s
`passwords` section. The Rust reference repository is pinned at
`6dae2fd3c1a2dce61ca11beb731bcce2b42b67ad`; its Rails application submodule is pinned at
`90b330024dec3e757c79b6a7e6568f93da8e3148`. The vector file has SHA-256
`4d5eb13617567e6dbd1974d880709d2a0d898cf4abc9ee66a6b432fb66a2c809`. It is generated by
`.agentlang/campfire-reference/reference-tools/rails_compat_vectors.rb` using that pinned Rails app.
Rails' `BCrypt::Password` implementation checks all generated digest/password pairs. This fixture
copies three of the five source digests and eight of the source's 40 verification pairs: four
successes and four failures. The hashes are fixed golden values and are never created by the
persistence provider or test oracle.

The source repository is copyright 37signals, LLC and licensed under MIT. Its
`.agentlang/campfire-reference/MIT-LICENSE` is included alongside this fixture.

The copied pairs cover an ordinary password, a multibyte UTF-8 password, and the Rails 72-byte
password boundary. They do not independently cover a multibyte character split at byte 72.
