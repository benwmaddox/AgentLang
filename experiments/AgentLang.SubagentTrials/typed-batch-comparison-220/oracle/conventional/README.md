# Conventional typed batch scorer

This scorer runs the nine frozen batch fixtures from `typed-batch-failure-216` against a fresh F# source build. Its independent Python model computes the expected complete result, original input, error index, old subscription ID, and exact cause code and message. The F# projection checks full entity membership, exact native subscription instants, input preservation, and collateral customer, product, invoice, payment, and email metadata; it rejects unknown IDs instead of dropping them from the projection.

The disposable scorer project compiles only the participant's `Domain.fs` and `Operations.fs` with this control adapter. It does not include `SelfTests.fs` or trust participant expectations. The failure adapter requires the nominal `SubscriptionRenewalFailure` record with exactly typed `Index`, `OldId`, and `Cause` fields, then reads the exact cause code and message. Since the business `Store` stores subscriptions in a map, the adapter reconstructs the fixture's subscription-list order from input rows and appends successful requested IDs in request order; it does not claim that the native map exposes list ordering.

Run `python -B experiments/AgentLang.SubagentTrials/typed-batch-comparison-220/oracle/conventional/score_conventional.py --participant <source-directory>` from the repository root. `--participant` can be a directory containing `Domain.fs` and `Operations.fs`, or the `Operations.fs` path (in which case `Domain.fs` is taken from the same directory). Each run and all failed attempts are retained below `.agentlang/typed-batch-comparison-220/fsharp/attempts`. `--calibrate` exercises the correct, always-zero, last-error, changed-message, subday-time, unknown-customer, nominal-record, old-ID-type, cause-type, row-ID, and copied-source hash controls.
